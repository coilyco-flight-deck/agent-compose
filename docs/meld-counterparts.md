# Meld counterparts

A two-sided meld names the role holding the other side with an optional
`counterpart`. The counterpart never declares the meld, because the body is
written to the deferring side, and loading fails when it does. A meld with a
counterpart is two-sided by construction, which is the test that separates
shared doctrine from a roster-wide rule wearing a meld's clothes. A meld
without one is a shared obligation with no mirror, which is the honest reading
of `evidence`.

The counterpart is a relationship, not authority. It grants no permission,
changes no delivery, and only tells evaluation coverage that the mirror role
owes the boundary case.
