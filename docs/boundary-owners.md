# Boundary owners

A two-sided boundary names the role holding the other side with an optional
`owner`. The owner never declares the boundary, because the body is
written to the deferring side, and loading fails when it does. A boundary with a
owner is two-sided by construction, which is the test that separates
shared doctrine from a roster-wide rule wearing a boundary's clothes. A boundary
without one is a shared obligation with no mirror, which is the honest reading
of `evidence`.

The owner is a relationship, not authority. It grants no permission,
changes no delivery, and only tells evaluation coverage that the mirror role
owes the boundary case.
